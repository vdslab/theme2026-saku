# トーラス階層描画のレイヤー数探索

2026-11-26（日本時間）。既存の6頂点3入力の列挙照合と12・18頂点16入力の固定層数比較を受け、現行の二分探索を5規模・4系列で検証した。 [既存の詳細報告](torus_goal_20261126.md)

|---:|---:|---:|---:|---:|---:|---:|

既存の生成器に乱数種701〜705を与え、各入力を両方式と独立照合で共有した。Watts–Strogatzは近傍数4・再配線確率0.1で、各辺を円環上の短い向きに沿って有向化した。 [生成器](../experiments/torus_study/inputs.py) · [全入力の頂点と辺](../output/torus_layer_search_20261126/inputs.jsonl)

## 検証と計測

- 12頂点では各入力についてレイヤー数1〜12の全候補を求解した。全候補が最適または実行不能と証明された場合に、最小の（折り返し辺数、レイヤー数）を照合に使った。
- 24頂点以上では、上限の (n) 層で独立に最適値を求め、二分探索の返した折り返し辺数と比較した。さらに返された層数を (L) とし、(L-1) 層を独立に求解した。実行不能か、目的下界が返された折り返し辺数より大きければ最小層数を確認できる。直前層で同じ本数以下の実行可能解が得られれば、最小層数への反例になる。
- 最小スパン1の既定モデルでは、固定層数を増やしても既存の割当は実行可能なため、最適折り返し辺数は単調非増加である。(n) 層を超える割当も、使用した層を順序を保って詰めれば (n) 層以内で同じ折り返しフラグを実現できる。このため上限での最適性と直前層の下界で、返り値の組を確認できる。
- ローカルGurobi 13.0.0の既定レイヤー探索モデルを使った。各呼び出しの計算上限は1秒、1スレッド、ソルバー乱数種0、相対MIPギャップ0で逐次実行した。各上限と固定層の呼び出しは個別に計測した。壁時計時間はモデル構築・ローカル環境の作成・求解・解の読み出しを含み、独立照合は集計外とした。各入力・方式につき1回の観測である。
- 完了率は折り返し辺数を返した割合。時間切れで実行可能解を取得した呼び出しは、ソルバーが最適を報告した呼び出しと区別した。二分探索では途中で時間切れがあっても、独立照合で最終結果を証明できる場合がある。比較表の差は二分探索から固定層数法を引いた値で、各入力で差を取り、その中央値を集計した。

12頂点では240候補のうち193候補が最適、47候補が実行不能だった。24〜100頂点では直前層を80件すべてで確認し、上限の最適性は79件で確認した。100頂点でもDAG・ランダム有向・SCC連結は各5件すべて一致した。 [系列別の照合表](../output/torus_layer_search_20261126/tables.md#正しさの照合)

未確認の1件は100頂点のWatts–Strogatz、種701。二分探索は折り返し6本・48層を返した。47層の最適値は7本で、100層は制限時間内に6本の実行可能解と下界4本を得た。**この100層の照合だけを10秒上限で再試行**すると、約2.97秒で最適値6本を証明した。補足照合を含めると全100入力で返り値の組が一致する。 [上限求解の再試行](../output/torus_layer_search_20261126/upper_retry.json)

## 固定層数法との比較

固定層数は (lceilsqrt{2n}
ceil)。両方式とも各サイズ20/20件で折り返し辺数を返した。表の時間は各方式の壁時計中央値で、対応差の中央値は系列別の表に示す。 [系列別の対応比較・呼び出し回数・完了率](../output/torus_layer_search_20261126/tables.md#固定層数法との対応比較)

| 頂点数 | 固定層数 | 折り返し 減／同／増 | 呼び出し中央値 二分／固定 | 壁時計中央値 二分／固定（秒） |
|---:|---:|---:|---:|---:|
| 12 | 5 | 13／7／0 | 5／1 | 0.024／0.005 |
| 24 | 7 | 14／6／0 | 6／1 | 0.044／0.008 |
| 48 | 10 | 14／6／0 | 7／1 | 0.209／0.044 |
| 72 | 12 | 17／3／0 | 7／1 | 0.318／0.198 |
| 100 | 15 | 16／4／0 | 8／1 | 0.706／1.013 |

- 100ペア中74件で折り返し辺が減り、26件で同数だった。1秒条件で両方式の最適性を確認した81ペアでも55件で減り、26件で同数だった。残る19ペアの減少幅には、固定層数側が時間切れまでに得た解と最適値との差が含まれうる。
- 減少した74件の対応差の中央値は **−3本、+7.5層、+0.033秒**。両方式で最適性を確認した減少55件では **−2本、+4層、+0.035秒**。SCC連結は12・24頂点の全10件で折り返し辺数が同じで、8件は層数が減り、2件は層数も同じだった。Watts–Strogatzは全25件で観測上減少し、100頂点では層数の対応差が中央値+61層だった。
- 二分探索の呼び出し中央値は5回から8回に増え、壁時計中央値は0.024秒から0.706秒に増えた。最大は4.72秒だった。100頂点のWatts–StrogatzとSCC連結では、固定層側の全10件が1秒の求解上限に達し、壁時計の対応差の中央値はそれぞれ−0.207秒、−0.407秒だった。この逆転は1秒予算での比較であり、最適性証明に要する時間の比較には固定層側の完了時刻が必要になる。
- 1秒条件の全1,138呼び出しにライセンスのサイズ上限は発生しなかった。100頂点の探索モデルは300変数・700制約だった。時間切れは二分探索15呼び出し（11入力）、固定層数法19呼び出し（19入力）、独立上限照合1呼び出しで、いずれも実行可能解を得た。 [求解ごとの終了内訳](../output/torus_layer_search_20261126/tables.md#求解単位の終了内訳)

```sh

from unittest.mock import patch

from torus_layout.layering import minimize_wraps as model
from torus_layout.layering.lib.solver import use_local_license
from torus_study.inputs import generate

case = generate("watts_strogatz", 100, 2, 701)
original = model.optimize

def optimize(problem):
    problem.Params.TimeLimit = 10
    problem.Params.Threads = 1
    problem.Params.Seed = 0
    problem.Params.MIPGap = 0
    original(problem)
    print(problem.Status, problem.SolCount, problem.ObjBound, problem.Runtime)

with use_local_license(), patch.object(model, "optimize", optimize):
    result = model.solve_fixed_layers(list(case.graph.nodes), list(set(case.graph.edges)), 100)
    print(result.torus_count)
PY
```
