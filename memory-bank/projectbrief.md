# Project Brief: トーラス階層割当・交差削減システム

## プロジェクト概要

トーラスを含む階層グラフの階層割当と交差削減を数理最適化によって実現する統合システム。サイクルを含むグラフを階層的に可視化し、エッジの交差を最小化する。

## 主要目標

1. **トーラス辺の自動判定**: 階層が減少する辺（トーラス辺）を自動的に識別
2. **階層割当の最適化**: 複数の手法で階層を割当（厳密解・ヒューリスティック・2段階）
3. **交差削減**: 階層内のノード順序を最適化して交差数を最小化
4. **階層数の推定**: グラフの特性から適切な階層数を自動推定
5. **高品質な可視化**: ダミーノード挿入とトーラス表現による可視化

## スコープ

### 含まれるもの

- **階層割当手法**（複数）
  - ILP: 整数線形計画法（厳密解、分散最小化）
  - IQP: 整数2次計画法（エッジスパンの2乗最小化）
  - ヒューリスティック: 高速な近似解
  - 2段階法: トーラス辺最小化＋バランス調整
  - バイナリサーチ: 最小階層数探索
- **交差削減**
  - ILP: 厳密な交差最小化
  - ヒューリスティック: 重心法による高速交差削減
- **階層数推定**
  - グラフ直径法
  - 最長サイクル長法
  - FAS（Feedback Arc Set）法
  - SCC-DAG法
- **可視化機能**
  - ダミーノード挿入
  - トーラス接続の視覚化
  - レイヤー順序の反映
- **包括的なテストスイート**

### 含まれないもの

- リアルタイム最適化
- Webインターフェース
- 大規模グラフの分散処理

## 主要制約

1. Gurobiライセンス必須（Academic License）
2. 中規模グラフを想定（〜100ノード程度）
3. トーラス辺は階層の逆方向へ進む辺
