# radial＋Algo2＋UNWIND と現行global siftingの再比較

現行globalは30件すべてで完成図を返し、radial＋Algo2＋UNWINDは17件で返した。比較できた17件では、幾何交差はglobalで少ない10件、同数4件、多い3件だった。前回もこの17件に絞ると同じ内訳で、入力ごとの幾何交差の差も17件すべて一致した。

中心線総延長の中央値差は −3.63層間隔（11／0／6）。完成図17ペアでは、ダミー間線分どうしの幾何交差は双方とも0。円環沿いではradial側の折れが少ない傾向があり、境界を通る元辺はglobal側で減ることが多かった。ランダム方向と有向閉路なしではglobal側で交差が減ることが多く、後段全体は延びる傾向があった。

radial側の失敗13件は分割なしBKの層内順序制約の循環による `UnsplitBlockOrderError`。合成2件は `ws-18-17-random` と `ws-24-17-ring`。公開11件はSampson 3件、UKfaculty 4件、macaque 4件。各失敗でも後処理後までの埋め込みを保存した。

入力ごと、方式ごとに照合しても、sifting直後から後処理後までの埋め込み交差数は全60試行で同じだった。境界を通る元辺数はこの間にradialで27件、globalで29件変わった。交差数の差はsifting直後に現れており、後処理は同じ交差数でも境界の通り方が異なる図を返した。

前回の幾何交差は30ペアで22／4／4。今回も完成図がある17入力に限ると、前回も今回も中央値差−1、10／4／3。今回の差から前回の差を引くと、17件すべて0だった。今回の30件は前回と層数、ダミー数、sifting直後の交差数も一致した。階層割当は今回改めて各入力で1回求めて共有した。完成図の結果は各構成全体の比較として扱う。

## 実際の処理経路と時間

- radial側は30件すべてで、radial sifting、Algo2、逐次UNWIND、切れ目DPの順に呼び出した。分割なしBKに合わせてダミー間の境界通過を優先した。従来経路は、先行UNWINDの後にDPで切れ目を選び、ダミー間に限定したUNWINDからの別候補も作る。必要に応じて切れ目を再計算し、境界通過の評価が良い候補を採用する。実際の追加呼び出しも入力別JSONに保存した。
- global側は `PipelineConfig()` の既定のglobal siftingと `joint` による同時境界最適化を全30件で適用した。Algo2の呼び出しは0件。既定のフォールバックの発動は0件。
- globalは上限5ラウンドで、実行は2回が7件、3回が9件、4回が4件、5回が10件。radialは対象層間ごとに5回で、入力あたりの層間処理回数は15〜135回、中央値35回。
- 両方式の後段上限は1試行60秒。タイムアウトは0件。失敗を含む実測の最大はradial 7.62秒、global 29.15秒だった。

以下の時間は失敗を含む30ペアの試行時間。座標割当の欄にはエラーまでの時間も含む。

主比較で保存した後処理後の埋め込みを固定し、両方式の座標割当を分割ありBKで実行した。各方式で30件すべて完走した。セルの表記は主比較と同じ。
