# ステップ1：階層数の二分探索の正当性

対象：`src/torus_layout/layering/search.py` と `layering/lib/model.py` の現行定式化。
作成日：2026-11-10。

## 結論

トーラス辺数と階層数に比例関係は不要である。必要なのは、階層数Lを増やしても最小トーラス辺数が増加しないという単調性であり、現行制約ではこれを証明できる。
最小階層差が全辺で1なら上限n、一般の正整数なら上限nΛ（Λは最大最小階層差）で、全階層数を通じた最小トーラス辺数を達成できる。
したがって、各求解の最適性と実行不可能性を正しく判定できれば、二分探索により「トーラス辺数、次に階層数」という辞書式最適解が得られる。

## 1. 定義と前提

- 有限の有向グラフG=(V,A)、n=|V|≥1。
- 自己ループはない。各辺eの最小階層差λ_eは正整数。
- 階層数Lは正整数。空階層を許し、全階層を使用する制約や層容量制約は置かない。
- y_vは0,…,L−1の整数、t_eは0または1。
- 目的はT=Σ_e t_eの最小化。重みwは現行ステップ1の目的関数には使用されない。

Lを固定した実行可能解集合をF_Lとし、

```math
f(L)=\min_{(y,t)\in F_L}\sum_{e\in A}t_e
```

と定義する。実行不可能なLではf(L)=+∞とする。

現行の辺制約は、e=(u,v)について、

```math
\begin{aligned}
y_u-y_v &\le L t_e,\\
y_u-y_v &\ge \lambda_e-L(1-t_e),\\
y_v-y_u &\ge \lambda_e-Lt_e.
\end{aligned}
```

λ_e≥1なので、t_e=0ならy_v>y_u、t_e=1ならy_u>y_vとなり、同一階層の両端を持つ辺は認めない。

## 2. 単調性の証明

**命題1：任意の正整数LについてF_L⊆F_(L+1)。従ってf(L+1)≤f(L)。**

証明：L階層の任意の実行可能解(y,t)を、値を変えずにL+1階層で使う。

1. 変数の範囲は0≤y_v≤L−1から0≤y_v≤Lへ広がる。
2. 第1制約の右辺Lt_eは、Lを1増やすとt_eだけ増えるため緩くなる。
3. 第2制約の右辺λ_e−L(1−t_e)は、1−t_eだけ減るため緩くなる。
4. 第3制約の右辺λ_e−Lt_eは、t_eだけ減るため緩くなる。

よって同じ(y,t)が実行可能であり、目的値Σt_eも変わらない。最小値は増加しない。□

直感的には、空の階層を一つ増やし、元のノード配置とトーラス辺の指定を維持できる。
トーラス辺の周期スパンはLが増えると長くなるが、ステップ1はスパンを目的に含めないため、この証明には影響しない。

fは一定区間や急な減少を持ってよい。比例、直線、厳密な単調減少、連続性は不要である。

## 3. 上限nΛで十分であることの証明

Λ=max({1}∪{λ_e:e∈A})、U=nΛとする。

**命題2：任意のLで実行可能なトーラス辺の指定tは、U階層でも実現できる。**

証明：任意の実行可能解(y,t)を取る。yの小さい順に頂点を並べ、同順位は任意に解消して、各頂点へ異なる順位r_v∈{0,…,n−1}を与える。
全辺の両端は異なる階層にあるため、同順位の解消は辺の向きを変えない。

新しい配置をy'_v=Λr_vとする。すると、各辺の両端の階層差の絶対値d'_eは、

```math
\lambda_e\le\Lambda\le d'_e\le(n-1)\Lambda\le U-\lambda_e
```

を満たす。
現行制約は、t_e=0ならλ_e≤y'_v−y'_u≤U−λ_e、t_e=1ならλ_e≤y'_u−y'_v≤U−λ_eを満たせば成立する。
大小関係も保存しているため、同じtを持つ実行可能解がU階層で得られる。□

また、任意の頂点全順序に対してy'_v=Λr_v、順位が下がる辺だけt_e=1とすれば、同じ理由で実行可能解を構成できる。従って自己ループのない入力ではF_Uは空でない。

以上より、

```math
T^*:=\min_{L\ge1}f(L)=f(U).
```

通常のλ_e=1ではΛ=1、U=nである。使用済み階層を順位順に詰め直すことで、n階層以内に同じトーラス辺指定を収められる。

## 4. 二分探索の正当性

まずUで最適求解し、T*=f(U)を求める。次に判定述語

```math
P(L):\quad f(L)\le T^*
```

を考える。T*は全体最小値なので、これはf(L)=T*と同値である。
命題1・2により、Pは1,…,Uの範囲で「偽,…,偽,真,…,真」という形を取り、Uでは必ず真となる。
従って二分探索で最初の真を見つければ、

```math
L^*=\min\{L\ge1:f(L)=T^*\}
```

が得られる。これが「トーラス辺数を最小化し、その辺数を達成する最小階層数を求める」という辞書式最適化である。

二分探索の判定回数はO(log U)。最初のUでの最適化を含めても求解呼出し回数はO(log U)である。ただし、各整数計画の求解自体が高速であるという保証ではない。

## 5. 理論保証と現行実装の終了状態

理論上の二分探索は正当だが、現行実装はTIME_LIMIT/SUBOPTIMAL時の実行可能解のトーラス辺数も返す。この値は一般にf(L)ではなく上界である。

- 最初のUで得た解が未証明なら、それをT*と扱うことはできない。
- 候補LでT*以下の実行可能解が見つかれば、その候補は真と確定できる。
- 目的値がT*より大きい暫定解しか得られなくても、偽とは確定できない。
- 解が見つからない時間切れを実行不可能と扱うこともできない。解の取得前にSolCountの確認が必要である。

証明に対応させるには、最初のUで最適値を証明し、候補Lでは次の3値を区別する必要がある。

| 判定 | 根拠 | 探索の処理 |
|---|---|---|
| 真 | T*以下の実行可能解がある | 小さいLを探索 |
| 偽 | 実行不可能を証明、または目的の厳密な下界がT*を超える | 大きいLを探索 |
| 未確定 | 時間切れ等で上記どちらも証明できない | 境界を動かさず、追加求解または未証明として終了 |

UでT*を確定した後は、候補LにΣt_e≤T*を追加した実行可能性問題として解いてもよい。
その場合も「実行可能」「実行不可能を証明」「未確定」を区別する。
浮動小数点ソルバーの許容誤差を考慮し、取得した整数解の制約を検査する。

## 6. 適用範囲の注意

- 空階層禁止・層容量・固定端点階層等を加えた場合、集合の包含や上限の証明は再確認が必要。
- λ_e>1の場合、現行制約は通常辺にも階層差≤L−λ_eを課す。これは単なる「通常辺の最小差」以上の制約である。今回の証明はこの現行モデルに対して成立するが、一般化モデルの意図と一致するかは別途確認する。
- 自己ループは現行制約ではどのLでも実行不可能なので、入力で除外または別処理する。
- n=0は空グラフとして別扱いにし、実装上の返値規則を定める。

証明は現行のステップ1の目的と制約から直接導出しており、実験による観測には依存しない。
