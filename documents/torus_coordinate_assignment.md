# トーラス階層レイアウトの座標割当：実装と手法選定

2026-11-10

## 採用判断

このフレームワークでは、**交差削減で得た層内順序・巻き数を固定し、周期境界を含む全セグメントの変位を最小化する凸QP**を標準とする。長辺のダミー位置をさらに滑らかにしたい場合は曲がり罰則を加える。総変位を優先する用途にはLPを選ぶ。BKはソルバー不要の比較基準として残す。

これは「BKの反復数を増やす」という改善ではない。切開した平面で整列してから補正する構成から、最初からトーラスの普遍被覆上で目的関数と制約を定義する構成への変更である。今回実装したQP/LPは本プロジェクト用の定式化であり、下記論文のアルゴリズムをそのまま再現したものではない。

小規模15例の予備実験では、QPで二乗変位和が従来比4.92%減少し、LPでは絶対変位和が4.38%減少した。曲がり罰則付きQPは曲がり二乗和を15.09%減らす一方、総ユークリッド長は0.32%増えた。したがって曲がり罰則は既定値0とし、ユーザーが目的に応じて有効化する。大規模実データでの優位性は未検証である。

## 現状の何が不足していたか

現行BK系実装は完全な平面BKそのものではない。4方向の整列・圧縮・中央値統合の後に、巻き数を用いた4回の平滑化と周期間隔の射影が入っている。

しかし以下の制約がある。

1. `t_val != 0` または `psi != 0` の辺をBKの整列候補から除外する。トーラスにとって自然な辺が、切開位置によって整列対象から落ちる。
2. 最終層と先頭層の接続を、通常の隣接層と同じようには整列しない。
3. 射影は `z_i = y_i - i*g` に対して `0 <= z_i <= H-n*g` を課す。これは円周上の非重複に十分だが必要条件ではない。たとえば最大密度層では全頂点が `0,g,2g,...` に固定され、層全体の位相移動が失われる。
4. 平滑化は頂点次数で平均した値を、等重みのisotonic射影に渡す。全体の二乗辺長についての正確な射影勾配法でも、各層の厳密な部分最小化でもなく、単調改善や収束判定が用意されていない。
5. 平滑化によってBKのダミー整列が崩れる可能性があり、折れ曲がり自体の評価項もない。
6. 現行の衝突検出には同じ層対の辺ペアの走査がある。原論文BKの線形時間という性質を、そのままこの実装の実測・計算量に当てはめられない。

[BK原論文](https://kim246.wwwdns.kim.uni-konstanz.de/publications/bk-fshca-01.pdf)は、固定した層内順序の下で短い辺、釣り合い、長辺の直線性を重視する線形時間の手法である。[2020年の訂正](https://arxiv.org/abs/2008.01252)も参照した。訂正への対応と、周期境界に適した定式化は別の課題である。

## 今回の定式化

層方向はx、層内方向はyとする。層数をK、最小間隔をgとし、従来と同じ周期

\[
H=\max(1,\max_\ell |L_\ell|)g
\]

を用いる。層、層内順序、左右の巻き数t、上下の巻き数ψは固定する。

辺e=(u,v)の普遍被覆上の変位を

\[
d_e=y_v-y_u+H\psi_e,\qquad
h_e=x_v-x_u+Kt_e
\]

とする。これは描画の `end.y + vertical_winding * height` と同じ符号である。proper layeringされた通常のセグメントは左右境界の辺を含めて `h_e=1` になる。固定されたx成分は二乗ユークリッド長の最小化では定数なので、QPの目的関数から除いてよい。

各層の切開順序がv₀,…,vₙ₋₁なら、制約は

\[
y_{i+1}-y_i\ge g,\qquad y_{n-1}-y_0\le H-g.
\]

後者が先頭・末尾の周期間隔を守る。描画の開いた基本領域に合わせて全変数に

\[
-g/2+\epsilon\le y_v\le H-g/2-\epsilon
\]

を課す。εは境界上の点を避ける数値的余白で、ノードの表示半径ではない。旧射影のように各zᵢを同じ区間へ閉じ込めない。最大密度層でも一周期内の許された位相移動が可能になる。

### QP：標準

\[
\min_y\ \sum_e w_e d_e^2 + \lambda\sum_{(u,d,v)}(d_{dv}-d_{ud})^2.
\]

第二項は入次数・出次数がともに1のダミー頂点dでのみ使う。元頂点の分岐に直線性を強制しない。左右・上下の継ぎ目を含め、普遍被覆上の傾きの変化を評価する。水平スパンが1でない入力に曲がり罰則を指定した場合はエラーにする。一般のスパンへの拡張では `d_e/h_e` の差を用いる必要がある。

wは`SubdividedGraph.weights`を使う。現在の細分化では元辺の重みが各セグメントに伝わる。これは「元辺1本を同じ総重みで数える」目的とは異なる。長辺全体の総変位だけを重視する研究では、元辺IDと経路を明示的に保持して目的関数を変えるべきである。

重み・λが非負で巻き数が固定なら、目的は凸、制約は線形である。GurobiのOPTIMAL判定を得た場合だけ返す。ただしこれは**固定した周期・切開順序・巻き数に対する数値許容誤差内の最適性**であり、順序・巻き数・階層割当を含むトーラス描画全体の最適性ではない。目的は半正定値なので、平行移動や非連結成分などで座標解が一意とは限らない。

### LP：総変位を優先する代替

\[
\min_y\ \sum_e w_e|d_e|+\lambda\sum_{(u,d,v)}|d_{dv}-d_{ud}|.
\]

各絶対値に補助変数aを作り、`a >= d`, `a >= -d` としてLPにする。同じ周期制約・巻き数を使うため、QPと同じ実行可能領域で比較できる。

これは縦方向のL1変位の最小化であり、実際の辺の長さ `sqrt(h²+d²)` の和を直接最小化するものではない。LPは一部の辺を完全に水平にしやすい一方、同点解が多く、少数の辺へ変位が集中し得る。QPは大きい変位に強い罰則を与え、変位を分散させる。

分かりやすい例は巻き数合計1の閉路である。閉路上の変位和は必ずHになる。全辺を同時に水平にすることはできない。重み(1,2,4)、H=1なら、QPの最小値は `1/(1+1/2+1/4)=4/7`、LPは1になる。この解析解との一致をテストしている。

## 他の座標割当法をどうトーラス化するか

以下の「適用方法」「判断」は本フレームワークに対する設計上の考察であり、すべてを今回実装・計測したという意味ではない。

| 手法 | 特性 | トーラスへの適用方法 | 本フレームワークでの判断 |
|---|---|---|---|
| Brandes–Köpf | 整列ブロックと圧縮。長辺の直線性、速度、ソルバー不要が利点 | 巻き数分のオフセット付きブロック、周期間隔制約、最終層→先頭層の整列が必要 | 比較基準・高速プレビュー。単純な境界辺の追加だけでは不十分 |
| L1最小化／Graphviz系network simplex | 総変位を抑え、直線にそろいやすい。非一意解が多い | `|y_v-y_u+Hψ|` と周期差分制約。一般LPが明快な初期実装 | 今回LPを実装。総変位を最優先するときに採用 |
| 制約付き二乗変位QP | 大きい変位を強く抑制。重み・固定点・曲がり項を統合しやすい | lifted displacementと周期分離制約に置換 | 今回の標準。既存のGurobi基盤と相性がよい |
| 重心／rubber-band | 近傍平均へ移動。軽量、更新しやすい | 近傍を同じ被覆へ持ち上げ、次数を考慮した射影または部分QPで更新 | 大規模用候補。旧4回平滑化をそのまま最適化法とは呼べない |
| 中央値／pendulum | 外れた辺の影響を受けにくく、L1的な挙動 | 持ち上げた近傍の中央値と周期的な順序制約を組み合わせる | LPの近似候補。更新順依存、停滞、振動を評価する必要がある |
| 制約付きstress majorization | 全頂点対の距離や大域的な構造を反映 | x固定、層内順序と周期制約を付加。距離にトーラス計量を使う | クラスタ把握が主目的なら別モード。固定階層では自由度が限られる |
| 自由なトーラスstress／力学モデル | 非階層ネットワークの大域形状やクラスタのための方式 | 近い周期像を選択し、トーラス上で移動 | 階層・交差削減を維持する今回の座標工程の直接置換には不向き |
| ダミーを圧縮するSugiyama実装 | 長辺によるデータサイズ増大を抑える | 周期をまたぐ長辺の経路・オフセットを圧縮表現に保持 | 座標目的の代替というより、将来の大規模化施策 |

Graphvizの原論文は補助グラフを用いて座標を求める。[Gansner et al., 1993](https://www.graphviz.org/documentation/TSE93.pdf)。今回の汎用LPを「network simplexを実装した」とは呼ばない。周期差分制約を含む補助グラフへの厳密な変換と、専用ソルバーの検証は別作業になる。

重心／pendulum系については[Sanderの原資料](https://site.uottawa.ca/ordal/papers/sander/node15.html)を参照。制約付きQP・stressの関連例は[Dwyer, Koren, Marriott, 2006](https://research.monash.edu/en/publications/drawing-directed-graphs-using-quadratic-programming/)と[2009](https://research.monash.edu/en/publications/constrained-graph-layout-by-stress-majorization-and-gradient-proj/)。これらの自由配置・階層制約モデルは、今回の固定層内順序モデルと同一ではない。

トーラスstressの既存研究として[DoughNets, 2020（著者公開版）](https://www.research.ed.ac.uk/files/130593203/chen2020doughnets.pdf)、[It's a Wrap（著者公開版）](https://marvl.infotech.monash.edu/~dwyer/papers/itsawrap.pdf)がある。近い周期像を選び直す操作はクラスタ配置には有用でも、現在の巻き数を固定する交差削減工程とは区別する必要がある。ダミー圧縮については[Eiglsperger et al., 2005](https://jgaa.info/index.php/jgaa/article/download/paper111/2849/2656)を参照。

### BKを直接拡張しなかった理由

境界辺を整列に加える場合、等式は `y_v-y_u=-Hψ_e` になる。整列ブロックには単なる頂点の集合だけでなく、根からの周期オフセットを保持する必要がある。閉路に沿ったψの和が非零なら、すべての等式は両立しない。さらに各層の末尾→先頭の分離を加えると、平面BKで使える単純なDAGの圧縮だけでは処理できない。

オフセット付きunion-findと周期差分制約の実行可能性判定、整列を解除する規則まで作ると、BKの簡潔さが弱まる。今回のQPは「整列できる辺だけを選ぶ」代わりに、全辺の要求を柔らかい費用として同時に扱える。BKの長辺直線性が特に重要なら、先に保護したい経路を選び、その等式をQPへ加える混成方式が考えられる。ただし非零巻き閉路に強制直線性を与えると不可能になるため、実行可能性確認が必要である。

### 巻き数を最適化変数にしない理由

各辺を独立に最短周期像へ変更すると、既存の交差削減の前提と、閉路のホモトピー情報を変えてしまう。座標だけをmod Hで丸めることも同じ問題を起こす。

表示の代表座標を `y'_v=y_v-q_v H` に変えるだけなら、同じ辺を保つには `ψ'_uv=ψ_uv+q_v-q_u` と更新し、切開順序も回転させる必要がある。今回の最適化はこの整数的な切開変更を行わず、現行の代表領域内で解く。切開位置の離散探索とQPを交互に適用する方法は次段階の課題である。

## 比較実験

`experiments/evaluate_coordinate_methods.py` は4層、元頂点数12/24/48、各5シードの計15グラフを作る。異なる層の頂点対に確率2/nで有向辺を入れ、長辺を細分化し、1ラウンド交差削減を実行する。その結果を固定して4方式を比較する。層割当法の差を混ぜないため、層は `node % 4` に固定した。

すべての方式で周期、順序、巻き数、重みが同一。全セグメントの水平長は1。表は各指標の**全15例の合計を、従来BK＋4回平滑化の合計で割った比**であり、ケースごとの改善率の平均ではない。

| 方式 | 絶対変位和 | 二乗変位和 | ユークリッド長和 | 曲がり二乗和 |
|---|---:|---:|---:|---:|
| 従来BK＋平滑化 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| トーラスQP、λ=0 | 0.9791 | **0.9508** | 0.9799 | 0.9202 |
| トーラスQP、λ=1 | 1.0055 | 0.9694 | 1.0032 | **0.8491** |
| トーラスLP、λ=0 | **0.9562** | 0.9823 | **0.9756** | 0.9664 |

数値は[生データ](../experiments/results/coordinate_methods.csv)に保存した。実行時間はローカルのGurobi環境生成を含み、描画・交差削減は除外する。小規模ではQP/LPは概ね数ミリ秒だった。単一マシン・1回計測で、性能の優劣や大規模での上限を判断する根拠にはしない。

実際の総ユークリッド長を最重要指標にするなら、次の候補は `sum sqrt(h_e²+d_e²)` の凸最適化である。今回の結果でLPがこの指標に優れたことは、L1が常にユークリッド長に優れるという保証ではない。

## 実装の利用方法と互換性

`torus_layout.pipeline.run_pipeline`とCLIの既定値は、ユーザー指定により`brandes_koepf`とする。
QP・LPは`PipelineConfig.coordinate_method="torus_qp"` / `"torus_lp"`で明示的に選択する。

```python
from torus_layout.models import PipelineConfig
from torus_layout.pipeline import run_pipeline

result = run_pipeline(graph, PipelineConfig(
    coordinate_method="torus_qp", coordinate_bend_weight=0.0,
))
```

座標工程単体での呼び出し：

```python
from torus_layout.coordinates import assign_coordinates

coords = assign_coordinates(subdivided, crossing, method="torus_qp")
coords = assign_coordinates(subdivided, crossing, method="torus_qp", bend_weight=1.0)
coords = assign_coordinates(subdivided, crossing, method="torus_lp")
```

互換性のため`assign_coordinates`単体のmethod省略時は従来BKとし、`compute_positions`、旧`src/old_torus_layout/main.py`、旧`src/old_torus_layout/coordinate_assignment/brandes_koepf.py`も従来動作を維持した。**旧mainをそのまま実行しても新方式には切り替わらない。** 新方式は上記の新パイプラインまたは座標APIから使用する。旧比較実験を再現する際は`PipelineConfig(coordinate_method="brandes_koepf")`を明示する。

QP/LPにBKの前処理は不要なので実行しない。`smooth_iterations`はBKだけに適用する。QP/LPは既存の`.env`によるGurobi環境を用い、ライセンス失敗や非最適終了を黙ってBKへフォールバックしない。頂点サイズ、ラベルの衝突、辺とノードの重なり、同層辺のルーティングを解決する機能は含まない。

再現コマンド：

```sh
PYTHONPATH=src MPLBACKEND=Agg MPLCONFIGDIR=/private/tmp/torus-layout-mpl ./theme2026-saku/bin/python experiments/evaluate_coordinate_methods.py --local-solver --draw
PYTHONPATH=src MPLBACKEND=Agg MPLCONFIGDIR=/private/tmp/torus-layout-mpl ./theme2026-saku/bin/python -m pytest src/torus_layout/tests -q
```

`--local-solver`は小規模比較実験でインストール済みのローカルライセンスを明示的に使うオプション。通常のアプリケーション経路のライセンス設定は変更しない。

検証には、正負の巻き数を含むランダム例、左右境界辺、周期間隔、入力不変性、QP/LPそれぞれの目的値の非悪化、空入力、曲がり項、重み付き閉路の解析解、新パイプラインへの接続を含む。最適化の保証対象はモデル内の間隔と費用であり、画面上の可読性全般ではない。

## 次に検証する事項

- 実際のcyclic/Watts–Strogatz/実データの階層割当結果で、層密度、巻き辺率、ダミー比率を分けた評価を行う。
- λを0/0.1/1/10で比較し、曲がり・長さのPareto曲線を調べる。現時点でλ=1を万能な既定値とはしない。
- 大規模では周期差分制約に対応する疎なQP、射影勾配・層ごとの部分最小化、長辺圧縮を比較する。元頂点数だけでなく細分化後サイズを報告する。
- 表示の安定性が重要なら、第一目的の最適値を保った二段階目で旧座標からの移動量を最小化する。小さい係数を無説明に足して第一目的を変えるのは避ける。
- 継ぎ目付近での可読性は境界をまたぐ経路追跡と別途評価する。固定順序・巻き数を保つproperな層間セグメントの交差関係は維持できるが、重なりや退化、同層辺を含む一般の幾何交差まで一律には保証しない。

最終回帰検証：新パッケージの187テストが成功。旧ソース・設定74ファイルの保護ハッシュは一致。通常import確認と`git diff --check`も成功。
