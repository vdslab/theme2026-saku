# Active Context: トーラス階層割当・交差削減システム

## 現在の作業フォーカス

**ステータス**: ✅ **本番利用可能・機能拡張完了**

プロジェクトは2026年2月の初期実装から大幅に進化し、複数の階層割当手法、交差削減機能、階層数推定機能を統合した包括的なシステムに成長しました。

## 最近の変更（重要な順）

### 1. 平坦トーラス交差削減の実装 (2026年6月)

**変更内容**:

- 環状階層構造によるトーラス交差削減
- 巻き付き数（alpha）変数の導入
- 対称性を利用した変数削減（x[k,u,v]は常にu<v）
- 推移律制約による順序一意性保証

**特徴**:

- トーラス境界をまたぐエッジの交差を正確に計算
- 多重交差にも対応（連続変数c）
- 無駄な境界またぎを抑制するペナルティ項

### 2. ダミーノード挿入機能 (2026年6月)

**変更内容**:

- 長距離エッジ（階層差2以上）へのダミーノード自動挿入
- 環状構造を考慮した距離計算
- 挿入後のエッジとt_valの自動更新

**効果**:

- 可視化の大幅な改善
- 交差削減の精度向上
- エッジの視覚的整理

### 3. 複数の階層割当手法の実装

#### torus_ilp.py - ILP版（固定階層数）

- One-hot変数による距離離散化
- エッジスパンの2乗をILPとして定式化
- 固定階層数Lでの厳密解

#### torus_iqp.py - IQP版（階層数変数）

- 元のtorus.pyの後継実装
- 階層数L_maxを最適化変数として扱う
- エッジスパンを直接2乗

#### torus_heuristic.py - ヒューリスティック版

- Tarjan法によるSCC分解
- SCC-DAGの最長パス計算
- モジュラーランク最適化
- 高速実行（厳密解の100倍以上高速）

#### torus_two_stage.py - 2段階法

- ステップ1: トーラス辺数最小化
- ステップ2: 固定トーラス辺でバランス調整
- 両段階の実行時間を記録

### 4. 階層数推定機能の実装

**実装した手法**:

- **graph_diameter.py**: グラフ直径による推定
- **longest_cycle_length.py**: 最長サイクル長による推定（デフォルト）
- **estimate_layer_count_via_fas.py**: FASサイズによる推定
- その他の実験的手法

**統合**:

- main.pyで`--layer`引数により選択可能
- デフォルトは`cycle_length`

### 5. メインスクリプトの統合 (main.py)

**機能**:

- コマンドライン引数による柔軟な実行制御
- グラフ生成 → 階層数推定 → 階層割当 → 交差削減 → 可視化の一貫したフロー
- 実行時間の計測と表示

**引数**:

```bash
--node: ノード数
--cycle: サイクル数
--prob: エッジ確率
--seed: シード値
--layer: 階層数推定法 (diameter, cycle_length)
--assigner: 階層割当法 (ilp, iqp, heuristic, two_stage, torus, torus_edge)
--l: 階層数の手動指定
```

## 重要なパターンと学習

### Big-M法の適用

**学習**: M = n が安定的に動作

- ノード数と同じ値を使用
- 階層範囲 [0, n-1] と整合

**実装の一貫性**: すべての階層割当手法で共通

### One-hot変数による2乗項の線形化

**学習**: ILPで2乗最小化を実現する革新的手法

```python
# K_uv = {lam, lam+1, ..., M-1}
x[u,v,k]: エッジ(u,v)の距離がkかどうか（バイナリ）
制約: Σ_k x[u,v,k] = 1
     Σ_k k*x[u,v,k] = y[v] - y[u] + M*t
目的関数: Σ_(u,v) Σ_k (k² * x[u,v,k])
```

**利点**: IQPよりも安定的で計算が速い場合がある

### 平坦トーラス交差削減の定式化

**学習**: 環状構造と巻き付き数の導入が鍵

- 最後の階層の次は最初の階層（環状）
- alpha変数で境界またぎを表現
- 対称性利用で変数数を半減

**実装の工夫**:

```python
def get_x(k, u, v):
    if u < v:
        return x[k, u, v]
    else:
        return 1 - x[k, v, u]
```

### ダミーノード挿入の効果

**学習**: 長距離エッジの分割は可視化と交差削減の両方に有効

- 視覚的な整理
- 交差計算の精度向上
- トーラス境界の扱いの簡素化

## アクティブな決定事項

### パラメータ設定（階層割当）

**ILP/IQPのデフォルト値**:

- **α = 100**: 階層数を最優先
- **β = 1**: エッジスパン最小化は副次的
- **γ = 100**: トーラス辺を強く抑制（ILPでは1000→100に調整）

**理由**: テスト結果から経験的に決定

### デフォルト手法の選択

**階層割当**: `ilp` (torus_ilp.py)

- 固定階層数での厳密解
- 安定した性能

**交差削減**: `ilp` (minimize_crossings_ilp.py)

- 厳密な交差最小化
- 中規模グラフで実用的な速度

**階層数推定**: `cycle_length` (longest_cycle_length.py)

- 最長サイクル長を推定
- サイクリックグラフに適している

### ダミーノード挿入の閾値

**決定**: 階層差2以上のエッジに挿入

**理由**: 階層差1は視覚的に許容可能、2以上は煩雑

## 開発における教訓

1. **定式化の重要性**: One-hot変数による線形化など、数理的な工夫が性能を左右
2. **モジュール化の価値**: 独立したモジュールは拡張と保守を容易にする
3. **段階的アプローチ**: 階層割当と交差削減を分離することで各々を最適化
4. **ヒューリスティックの必要性**: 厳密解が遅い場合の代替手段として重要
5. **可視化の影響**: ダミーノード挿入のような視覚的改善が全体の品質を向上
