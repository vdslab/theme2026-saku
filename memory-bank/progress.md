# Progress: トーラス階層割当・交差削減システム

## 完成している機能

### ✅ コア機能（階層割当）

1. **ILP階層割当 (torus_ilp.py)**
   - One-hot変数による距離離散化
   - エッジスパンの2乗最小化（ILP定式化）
   - 固定階層数での厳密解
   - Big-M法によるトーラス辺判定

2. **IQP階層割当 (torus_iqp.py)**
   - 階層数を最適化変数として扱う
   - エッジスパンの直接2乗最小化
   - 元のtorus.pyの後継実装

3. **ヒューリスティック階層割当 (torus_heuristic.py)**
   - Tarjan法によるSCC分解
   - SCC-DAGの最長パス計算
   - モジュラーランク最適化
   - 高速実行（厳密解の100倍以上）

4. **2段階階層割当 (torus_two_stage.py)**
   - ステップ1: トーラス辺数最小化
   - ステップ2: 固定トーラス辺でバランス調整
   - 各段階の実行時間記録

5. **バイナリサーチ階層割当 (torus_binary_search.py)**
   - 最小階層数の探索

6. **バランス調整関数群 (torus_balance.py)**
   - 複数のバランス調整手法
   - トーラス辺固定での最適化

### ✅ コア機能（交差削減）

1. **ILP交差削減 (minimize_crossings_ilp.py)**
   - 平坦トーラス上の厳密な交差最小化
   - 環状階層構造
   - 巻き付き数（alpha）変数
   - 対称性を利用した変数削減
   - 推移律制約による順序一意性保証

2. **ヒューリスティック交差削減 (minimize_crossings_heuristic.py)**
   - 重心法による高速交差削減
   - サイクリックシフト最適化
   - 反復的改善

### ✅ 階層数推定機能 (layer_length/)

1. **graph_diameter.py**: グラフ直径による推定
2. **longest_cycle_length.py**: 最長サイクル長による推定（デフォルト）
3. **estimate_layer_count_via_fas.py**: FASサイズによる推定
4. **estimate_max_cycle_rm_dfs.py**: ランダムDFSによる推定
5. **longest_path_scc_dag.py**: SCC-DAG最長パスによる推定
6. **scc_node_count.py**: SCC最大ノード数による推定

### ✅ 可視化機能 (drawing/)

1. **draw_torus.py**
   - トーラス辺の境界接続描画
   - ダミーノードの黒点表示（オプション）
   - レイヤー順序の反映
   - ノードとエッジの重なり回避
   - FancyArrowPatchによる高品質な描画

### ✅ ライブラリ機能 (lib/)

1. **create_gurobi_env.py**: Gurobi環境作成
2. **insert_dummy_node.py**: ダミーノード自動挿入
3. **generate_torus_graph.py**: テストグラフ生成
4. **scc_decomposition.py**: 強連結成分分解

### ✅ メインスクリプト

1. **main.py**
   - コマンドライン引数による柔軟な実行
   - 完全なパイプライン（推定→割当→削減→描画）
   - 実行時間計測
   - 詳細な結果出力
