# Product Context: トーラス階層割当・交差削減システム

## なぜこのプロジェクトが存在するのか

階層グラフ（Hierarchical Graph）の可視化において、サイクルを含むグラフは従来の手法では対応できない。さらに、単に階層を割り当てるだけでなく、エッジの交差を最小化し、視覚的に理解しやすいレイアウトを実現する必要がある。トーラス構造を用いることでサイクルを含むグラフを階層的に表現し、数理最適化で交差を削減することで、高品質な可視化を実現する。

## 解決する問題

### 主要な課題

1. **サイクルを含むグラフの階層表現**: 従来のDAG前提の階層割当では、サイクルを含むグラフを扱えない
2. **エッジの交差問題**: 階層グラフでエッジが複雑に交差すると可読性が大幅に低下
3. **長距離エッジの処理**: 複数階層をまたぐエッジは視覚的に煩雑
4. **階層数の決定**: 適切な階層数の選択は試行錯誤が必要
5. **計算効率**: 厳密解の計算時間と解の品質のトレードオフ

### 解決方法

- **数理最適化**: Gurobiを用いた整数計画法により厳密解を保証
- **複数の手法提供**: ILP、IQP、ヒューリスティック、2段階法など、用途に応じた選択肢
- **交差削減の統合**: 階層割当後に交差を最小化するステップを追加
- **ダミーノード挿入**: 長距離エッジをダミーノードで分割し視覚的整理
- **階層数の自動推定**: グラフの特性（直径、最長サイクル等）から推定

```bash

draw_torus(V, A, layer_dict, t_val, order, draw_dummy_nodes=True)
```

### 出力

- 各ノードの最適な階層割当
- トーラス辺の識別
- 交差を最小化したノード順序
- 高品質な可視化（ダミーノード含む）
- 実行時間とメトリクス

### 期待される結果

- **DAG**: トーラス辺なしで自然な階層構造、交差最小
- **サイクリックグラフ**: 必要最小限のトーラス辺で階層表現、交差削減
- **可視化**: トーラス辺を視覚的に区別、ダミーノードで長距離エッジを整理

## どのように動作すべきか

### ワークフロー

1. グラフデータ（V, A）を入力
2. 階層数を推定（または手動指定）
3. 階層割当を実行（選択した手法で）
4. ダミーノードを挿入
5. 交差削減を実行
6. 結果を可視化

### 重要な振る舞い

- **柔軟性**: コマンドライン引数で手法・パラメータを選択可能
- **透明性**: 最適化の結果（階層数、トーラス辺数、交差数、実行時間）を出力
- **ロバスト性**: エッジの重複を自動除去、エラー時はIISを表示
- **段階的最適化**: 階層割当 → 交差削減の2段階アプローチ

## 主要な手法

### 階層割当手法

1. **ILP** (torus_ilp.py):
   - 整数線形計画法
   - エッジスパンの分散を最小化
   - 固定階層数で最適解

2. **IQP** (torus_iqp.py):
   - 整数2次計画法
   - エッジスパンの2乗最小化
   - 階層数を変数として最適化

3. **ヒューリスティック** (torus_heuristic.py):
   - 高速な近似解
   - SCC分解 + 最長パス + モジュラーランク最適化

4. **2段階法** (torus_two_stage.py):
   - ステップ1: トーラス辺数を最小化
   - ステップ2: 固定トーラス辺でバランス調整

5. **バイナリサーチ** (torus_binary_search.py):
   - 最小階層数を探索

### 交差削減手法

1. **ILP** (minimize_crossings_ilp.py):
   - 平坦トーラス上の厳密な交差最小化
   - 巻き付き数を考慮した定式化

2. **ヒューリスティック** (minimize_crossings_heuristic.py):
   - 重心法による高速交差削減
   - サイクリックシフト最適化
